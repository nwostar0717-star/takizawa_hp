# 施工事例の受付箱

実際に行った作業だけを書きます。ここに「未公開」の事例があるときだけ、事例記事が作られます。
書くのは本人が確認した事実だけ。分からない項目は空欄のままで大丈夫です。

## 書き方（1件ずつコピーして使う）

```
## 未公開：YYYY-MM-DD 作業名
- 作業内容：
- 担当範囲：（例：仕入れから交換まで本人／お客様手配の商品を取付）
- きっかけ・交換理由：
- 写真：（images/works/ に置いたファイル名、または「後日送る」）
- 掲載許可：（取得済み／未確認）
- 書いてよい補足：（場所の種類、地区名など。書きたくないものは書かない）
```
